🎨 Variables en CSS

Las variables CSS mejoran la reutilización de estilos y permiten construir interfaces más mantenibles.

🌍 Variables Globales

Se declaran en :root y están disponibles en todo el documento.

:root { --color-primario: #0077cc; }

📦 Variables Locales

Se definen dentro de un selector y solo afectan a ese contexto.

.tarjeta { --color-secundario: #f0f0f0; }

🌓 Modo Claro/Oscuro

Pulsa el botón para cambiar el tema utilizando las mismas variables.
